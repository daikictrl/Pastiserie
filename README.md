# SWEETMEATS - Artisanal Pâtisserie & Traiteur

A modern, multilingual web application for **SWEETMEATS**, an artisanal pâtisserie and catering service. Built with React 19 and Tailwind CSS 4, featuring a sleek, responsive design and seamless user experience.

## ✨ Features

- **Multilingual Support**: Toggle between French and English effortlessly.
- **Responsive Design**: Optimized for all devices, from mobile to desktop.
- **Interactive UI**: Smooth animations powered by Framer Motion.
- **Product Gallery**: Showcase of artisanal cakes, pastries, and savory delights.
- **Direct Contact**: Integrated WhatsApp link for instant orders and inquiries.
- **Modern Tech Stack**: Built with the latest versions of React and Tailwind CSS.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion (motion/react)](https://www.framer.com/motion/)
- **Internationalization**: [i18next](https://www.i18next.com/)
- **Icons**: [Iconify](https://iconify.design/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/daikictrl/Pastiserie.git
   cd Pastiserie
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Environment Setup:
   Create a `.env.local` file in the root directory and add your API keys (if applicable):
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:3000`.

## 📦 Deployment

To build the project for production:

```bash
npm run build
```

The production-ready files will be generated in the `dist/` folder.
